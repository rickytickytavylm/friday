# Чёрная пятница · видеокурсы 7 700 ₽

Лендинг распродажи видеокурсов. Стилистика — по референсу givingli.com:
тёплый крем + чернильный + красный, дисплейная типографика (Onest),
плавающие карточки в хиро, нумерованные секции, сплошные полосы.

Статика: `index.html` + `styles.css` + `app.js` + `config.js`.
Можно отдать с любого статик-хостинга или через `npx serve .`

## Перед запуском заполнить (`config.js`)

- `PAY.*` — ссылки оплаты по цене 7 700 ₽ для каждого из 4 курсов.
  Пока ссылки пустые — кнопка вежливо дёргается и никуда не ведёт.
- `OLD_PRICE.*` — старые цены для зачёркивания (у СДВГ уже стоит 9 900 ₽,
  остальные — по ТЗ «[старая цена]» — уточнить).
- `BF_END` — дедлайн акции (сейчас 1 декабря 2026, 23:59 МСК).
- `TRACK_URL` — трекинг просмотров и кликов на оплату
  (по умолчанию тот же контур, что у landing_coda: `/api/coda/hit`).
  Если для ЧП нужен отдельный эндпоинт — поменять здесь.

## Места под изображения (размечены `data-photo`)

- `data-photo="hero"` — большая сцена в первом экране:
  Шуров крупно по центру, Низова рядом, психологи вокруг.
  Пока — красивая заливка (тёмно-красный градиент + рамка + подпись).
- `data-photo="course"` ×4 — обложки курсов (16:8.5).
- `data-photo="person"` ×6 — фото команды (4:5).
  Пока — тёмная плашка с инициалами.

Когда будут реальные картинки: заменить `<div class="ph…">` на
`<img>`/`picture` с теми же классами-контейнерами — сетка не поедет.
